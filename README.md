# Cohen Marley Cox Portfolio

A responsive personal portfolio built with semantic HTML, modern CSS and a tiny JavaScript layer.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and dynamic year

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

This repository is structured as a static site and can be served directly by GitHub Pages.
