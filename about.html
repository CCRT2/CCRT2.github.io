THE PERSON BEHIND THE SYSTEMS

Curious by default.
Serious about the work.

I’m interested in the layers beneath technology: how systems behave, where they fail, how they can be secured, and what happens when you build something from first principles.

HOW I THINK

Understand the system.
Then improve it.

I like difficult technical problems because the answer usually lives one layer deeper than the obvious solution. That mindset shapes how I approach cybersecurity, AI, software and infrastructure.

I learn by building. I spin up labs, write prototypes, test ideas, break things safely, document what happened, and carry the useful parts into the next project.
